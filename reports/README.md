# Example Reports

These reports illustrate analyses of public or local Java/Spring projects.
They are examples, not a product specification and not results that apply to
another repository.

Several reports are archived pre-SystemLens investigations. Their references to
the retired `cccr` command, Semgrep, historical indexes, or legacy assets are
historical evidence only and must not be used as current operating
instructions. Regenerate examples with `scripts/generate_example_reports.py`
to use the current `systemlens export microservices` interface.
