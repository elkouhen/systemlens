Get a verified map in three commands

At the root of a Java/Spring repository, run systemlens init, systemlens doctor, then systemlens index. Export an interactive graph with systemlens export microservices --html architecture.html and use it in a review, investigation, or design discussion.

Answer architecture questions with evidence

SystemLens creates a local inventory of the resources that make up a Java/Spring system and exposes only source-evidenced links between them.

Microservices and APIs

Indexes Maven/Gradle projects, Spring application entry points, REST routes, and outbound Feign, RestTemplate, WebClient, or gateway calls.

Topics and data

Indexes Kafka topics, their producers and consumers, known Java message types, MongoDB collections, and the Java methods that access them.

Supporting evidence

Also retains build dependencies, OpenAPI contracts, Spring properties, and optional Kafka manifests or Kubernetes capacity facts.

Relations in the graph

API calls

A microservice provides a REST route or calls an API. A direct microservice-to-microservice link is added only when the target is explicit and uniquely resolved.

Topic read/write

A microservice writes to a topic by publishing and reads from it by consuming. A concrete producer/consumer match creates a directed link between the two services.

MongoDB read/write

A microservice and its Java method are linked to each indexed MongoDB collection they read or write.

Every relation retains source evidence and confidence. Dynamic or unresolved values remain visible as evidence; SystemLens never turns them into a guessed internal dependency.

Use the map in your daily work

SystemLens keeps its findings local and grounded in source evidence, so the same map can support investigation, delivery, and architecture review without replacing engineering judgement.

uv tool install systemlens

# In the Java/Spring repository you want to understand
systemlens init
systemlens doctor
systemlens index

# Export a model for a review, an investigation, or a handoff.
systemlens export microservices --html architecture.html
